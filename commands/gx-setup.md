`gx-security` 스킬을 사용해 `$ARGUMENTS` 프로젝트의 **준비 확인만** 수행한다. 실제 검사로 자동 확대하지 않는다.
스킬의 공통 런타임 안내로 설치 경로·기존 상태·실행 환경을 확인한다. 호스트 Python을 무조건 실행하거나 프로젝트마다 설정 생성을 요구하지 않는다.
`gxsec.yaml`이 없어도 기본 설정을 사용할 수 있다. 사용자가 영구 설정 생성을 요청했을 때만 `init`을 수행하며 기존 파일을 덮어쓰지 않는다.
빠진 도구·DB·의존성 자료는 실제 준비 항목으로 안내한다. 비밀번호·토큰을 대화나 인자에 받지 않는다.
