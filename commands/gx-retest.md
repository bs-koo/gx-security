---
description: 저장된 발견사항 ID를 이어서 수정·정상 기능을 재검증
argument-hint: <finding-id> <소스경로>
---

`gx-security` 스킬의 **수정 재검증**으로 입력의 발견 ID·소스 경로를 처리한다.
이전 결과의 상태 저장소·실행 경로·원래 프로파일을 확인해 이어간다. 최신 결과에 ID가 없으면 확인한 이전 run ID를 지정한다. 새 기본 저장소로 바꾸거나 일반 새 검사로 대신하지 않는다.
동적 재검사는 원래 범위와 신뢰 정책·전용 fixture가 여전히 유효할 때만 활성화한다.
미발사·엔진 실패·규칙 변경·검사 범위 축소를 수정 완료로 바꾸지 않는다. source revision, 이전 run ID, 같은 finding ID와 실제 재검증 증거를 공유한다.
