`gx-security` 스킬의 **변경 점검**으로 `$ARGUMENTS`를 처리한다. 명시한 소스·기준 커밋을 유지하고 필요한 준비는 내부에서 확인한다. 별도 setup 호출을 요구하지 않는다.
기존 상태·선택한 실행 환경을 유지하며 공통 런타임 안내에 따라 `check`를 수행한다.
검사 실패·미설치·검토 대기는 INCOMPLETE다. 결과 건수만으로 안전을 선언하지 않는다.
보고서의 run ID와 report.html을 전달하며 기존 finding을 이번 부분 검사에서 보이지 않았다는 이유로 종료하지 않는다.
