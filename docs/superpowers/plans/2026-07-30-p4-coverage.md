# P4 커버리지 (v0.7.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 정적 스캔 후보를 "노이즈"가 아니라 "AI가 근거를 추적해 판정할 워크리스트"로 승격한다. 구체적으로 ① 접근통제를 정적+AI로 "충분히" 확정(소유권/권한 판정 사다리 + 근거 인용 매트릭스), ② 프론트엔드(Vue/Nuxt) XSS를 `detecting-xss` frontend 모드로 커버, ③ 동적을 AskUserQuestion 게이트로 대화형화, ④ 동적 확정을 "예상 증거 카드 + 사람 확인" 사람-인-더-루프로, ⑤ Windows(cp949) 인코딩 크래시를 근본 제거. v0.7.0 릴리스(P3 0.6.0 다음 minor — 최종 bump는 릴리스 시점 확정).

**Architecture:** 기존 2단계(스캐너 후보 → AI 컨텍스트 검증)와 안전 모델(scope_guard fail-closed, 정적=읽기전용)을 100% 유지한다. 무게중심만 이동 — **AI 2단계를 1급 산출물로 승격**하고 정적 도달 범위를 프론트엔드까지 넓힌다.
- ① 접근통제: `scan_access.py`가 후보마다 `context` 블록을 방출하고, **접근통제에만** 안전패턴 negative(`SAFE_CONTEXT_PATTERNS`)를 추가해 명백 안전 후보를 미리 제외한다. `SKILL.md`가 소유권 판정 사다리(secure/vulnerable/needs-runtime 3택 + 근거 file:line 인용)와 접근통제 매트릭스 산출을 명문화한다.
- ② XSS frontend 모드: `scan_xss.py`가 `frontend` 스택을 감지하고 `node_modules/dist/.nuxt/.output/*.min.js`를 제외한 뒤 SPA 싱크(`v-html`·`innerHTML`·`insertAdjacentHTML`·`document.write`·URL 싱크·`eval`)를 폴백으로 잡는다. `rules/xss-frontend.yml`(신규) 추가. `SKILL.md`가 **탐색→확인(AskUserQuestion)→스캔** 서브워크플로우를 구동한다. 프론트 룰은 semgrep의 .vue 파싱 한계상 폴백 regex가 주 경로이며 AI 2단계가 정밀도를 담당한다.
- ③ 동적 게이트: `auditing-*`·`exploiting-*` `SKILL.md`가 정적 완료 후 AskUserQuestion으로 "대상 실행 중?"을 묻고, 라이브니스 프로브(scope 통과 GET 1회)로 가동을 확인한 뒤 발사 인자를 구성한다. 비밀(계정/토큰)은 질문으로 받지 않고 `--creds-stdin`/env로 받는다.
- ④ 사람확인 확정: `attack_xss.py`가 반사만으로 `exploited:true`를 찍던 과대표기를 제거하고(감사 지적 #7), `verdict:"needs-confirmation"` + `evidence_expectation`를 방출한다. `SKILL.md`가 예상 증거 카드를 제시하고 사람 관찰(자유서술 우선)로 최종 판정한다. access soft-200·upload 미확정에도 동일 카드를 적용한다.
- ⑤ 인코딩: 공용 `tools/io_utf8.py`(신규)가 `configure()`(stdout/stderr UTF-8 강제)와 `emit_json()`(**UTF-8 바이트 직접 기록**)을 제공한다. JSON 계약 경로가 콘솔 코덱에 의존하지 않게 하는 것이 근본 수정이다.

**Tech Stack:** Python 3.11 · requests · PyYAML · unittest. 프론트 스캔은 순수 Python(외부 JS 툴 불요).

```python
# tools/io_utf8.py
"""JSON 계약을 콘솔 코덱에서 분리한다 — Windows(cp949) 파이프/캡처 크래시 근본 방지."""
import io, sys, json

def configure():
    for name in ("stdout", "stderr"):
        stream = getattr(sys, name, None)
        if stream is None:
            continue
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            buf = getattr(stream, "buffer", None)
            if buf is not None:
                setattr(sys, name, io.TextIOWrapper(
                    buf, encoding="utf-8", errors="replace", line_buffering=True))

def emit_json(obj, *, indent=2):
    data = json.dumps(obj, ensure_ascii=False, indent=indent)
    buf = getattr(sys.stdout, "buffer", None)
    if buf is not None:
        buf.write(data.encode("utf-8")); buf.write(b"\n"); buf.flush()
    else:
        print(data)
```
